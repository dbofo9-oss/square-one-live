# Square One Live — Clean Broadcast V5

A polished muted-black and charcoal TV layout for **barber_thebull** and **Cutz by Lito**. Features continuously scrolling tickers, rotating character spotlights, fullscreen TV mode, and a permanent Google review QR code.

## Included
- `index.html` — complete website with CSS and JavaScript included
- `characters.jpg` — new subdued artwork with correct **Cutz by Lito** lettering, cropped to remove the fictional market and sports statistics
- `bull.jpg` and `lito.jpg` — cropped mascot portraits for individual character spotlights
- `review-qr.png` — QR code for `https://g.page/r/CXeosN7EyCuJEAE/review`

## Updating your existing GitHub + Netlify website on Samsung

Your GitHub repository is `dbofo9-oss/square-one-live`. The Netlify project is `storied-raindrop-ad0f3e`. They are already connected.

1. Extract this ZIP in Samsung **My Files**.
2. In GitHub, visit `https://github.com/dbofo9-oss/square-one-live`.
3. Use **Add file > Upload files**, or the direct upload page `https://github.com/dbofo9-oss/square-one-live/upload/main`.
4. Upload `index.html`, `characters.jpg`, `bull.jpg`, `lito.jpg`, and `review-qr.png` from this folder. If GitHub asks whether to replace existing files with the same names, confirm the replacement. (If GitHub won't replace from Upload files, open `index.html` and use the edit pencil to replace its contents, or use github.dev.)
5. Select **Commit changes** to `main`. Netlify will deploy the updated site to your existing URL. Do **not** create a new Netlify project.

## Using it
- Tap the ⚙ icon to change shop ticker messages and the bottom announcement on the *current device*. Those local changes do not synchronize to other TVs or browsers.
- Use Fullscreen for the TV when supported.
- The feature area rotates every 20 seconds, with a pause button.
- The tickers scroll continuously. All prices, scores, and headlines are marked as not connected. **No fabricated live prices or scores are shown.**

## Future live data
A commercial display may need licensed market and sports data. This edition is a functioning *visual prototype* with an honest data status; it does not claim that market, sports, or news feeds are live.
